# Polymarket Opportunity Scanner

Небольшой бот-сканер (не трейдер!) для категорий **Политика** и
**Финансы** на Polymarket. Раз в `SCAN_INTERVAL_HOURS` (по умолчанию 6
часов) ищет рынки, где цена какого-то исхода попадает в диапазон
`[MIN_PRICE, MAX_PRICE]` (по умолчанию 0.80-0.95), с достаточным объёмом,
и шлёт в Telegram только **новые** находки — те, о которых ещё не
уведомлял.

## Что это НЕ делает

Не покупает, не продаёт, не анализирует новости. Механически можно найти
только цену и объём — согласуется ли эта цена с реальным положением дел
(а не просто "рынок уже старый/тонкий и цена случайно там зависла") —
решает человек, глядя на конкретный кандидат, или отдельный ИИ-анализ
(например, Claude), которому пересылают найденное с просьбой поискать
свежие новости и дать оценку.

Рекомендуемый рабочий процесс: бот присылает кандидата → ты пересылаешь
вопрос+исход+цену в чат с ИИ → тот ищет новости и контекст → сам
принимаешь решение, заходить или нет.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`:
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` — можно тот же бот, что у
  торгового бота (этот скрипт только шлёт сообщения, не слушает команды,
  конфликта из-за одного токена не будет), либо отдельный через
  [@BotFather](https://t.me/BotFather), если хочешь разделить чаты.

## Запуск

```bash
python -m src.main
```

Или задеплой как обычный воркер (Coolify/Render/Docker) — `Dockerfile`
уже готов. Постоянный volume на `/app/data` желателен, но не критичен:
максимум, что случится без него — при рестарте контейнера уже
увиденные кандидаты "забудутся" и придут повторным уведомлением один раз.

## Настройка фильтров

- `MIN_PRICE` / `MAX_PRICE` — диапазон цены исхода
- `MIN_VOLUME_USD` — отсекаем совсем неликвидные рынки (для них цена
  вообще ничего не значит — может двигаться от одной сделки на $50)
- `MAX_DAYS_OUT` — не показывать рынки, которые резолвятся очень нескоро
- `SCAN_INTERVAL_HOURS` — как часто проверять

## Дедупликация

Каждый кандидат (рынок + исход) запоминается в `data/scanner.db` после
первого уведомления. Повторно не уведомляем, пока кандидат остаётся в
диапазоне. Если цена вышла из диапазона (или рынок закрылся) и потом
снова вернулась — уведомим заново, это может быть значимое событие
(что-то произошло, цена дважды туда-обратно сходила).
