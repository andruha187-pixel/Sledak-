# polymarket-wallet-profiler

Исследовательский бот (НЕ торгует). Разбирает стратегию кошелька на 15m Up/Down рынках Polymarket:
выкачивает всю его историю, восстанавливает рынок в момент каждой сделки, следит вживую
и раз в 4 часа присылает в Telegram zip-отчёт.

## Что собирается на каждую его сделку (за DECISION_LAG_SEC до блока)
- **Сделка:** сторона, цена, размер, сумма, maker/taker (из on-chain OrderFilled), сколько уже набрал в окне, пауза с прошлого филла.
- **Окно:** секунд до конца/с начала, «цена для победы» (Chainlink на старте), отклонение в bps, z-score, справедливая вероятность Φ(z), edge = fair − ask.
- **Стакан Polymarket (обе стороны):** bid/ask/spread, объём топ-1 и топ-5, дисбаланс, сумма Up+Down ask/bid (сигнатура арбитража), поток сделок 30с, изменение mid за 5/15с (отставание PM).
- **Binance:** импульс 5/15/30/60/180с, CVD 15/60с, доля покупок, объём, реализованная вола 60с, дисбаланс стакана топ-10.
- **ТА 1m и 5m:** EMA 9/21/50, RSI, MACD hist, Bollinger %B, ATR, всплеск объёма.
- **Другие площадки:** Chainlink vs Binance, Bybit, Coinbase (базисы), фандинг Binance/Bybit, изменение OI за 5 мин.

Каждые 5 с сохраняется такой же снимок как **контроль** (моменты, когда он НЕ входил) — без этого стратегию не вычислить.

## Отчёт (report.md + CSV)
1. Обзор и PnL по окнам (пересчёт по резолву, помесячно, по активам).
2. Почерк: обе стороны в окне и цена пары, MERGE/REDEEM, maker-доля, филлы на окно, типовые размеры, винрейт и реальный edge по ценовым корзинам, тайминг.
3. Логика направления: берёт ли выигрывающую сторону, по импульсу, по тренду, по потоку.
4. AUC-таблица признаков «его входы vs все остальные моменты».
5. Дерево решений → правила-кандидаты (lift и покрытие) + важность признаков случайного леса.
6. Авто-гипотеза стиля.

`trades_enriched.csv` — все сделки с признаками (присылай его + report.md мне).

## Деплой (Render worker / Coolify)
Переменные:
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` — **новый** бот (не токен торговых ботов, иначе getUpdates будут конфликтовать)
- `TARGET_WALLET` (по умолчанию 0xb945…db68), `ASSETS=btc,eth`
- `DB_PATH=/data/profiler.db`, `OUT_DIR=/data/reports` — **обязательно на постоянный диск**, иначе после редеплоя всё заново
- `BACKFILL_SINCE=2026-03-01`
- Если Binance отдаёт 451 (US-регион): `BINANCE_REST=https://data-api.binance.vision`, `BINANCE_WS=wss://data-stream.binance.vision`
- `POLYGON_RPC` — свой RPC (Alchemy/QuickNode), если публичный режет запросы
- `ALERT_EACH_TRADE=1` — уведомление на каждый его филл (по умолчанию выкл.)

Команды: `/report` — отчёт сейчас, `/status` — здоровье потоков и прогресс истории, `/last` — последние 10 филлов.
